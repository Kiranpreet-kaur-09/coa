# Student Portfolio Website

## Files
- `index.html` — complete website structure
- `style.css` — design and responsive layout
- `script.js` — number-system converter and assignment file selection
- `assets/` — put your profile photo here

## Personal details to replace
Open `index.html` and replace:
1. `YOUR ROLL NO.`
2. `assets/profile.jpg` with your actual photo
3. CV button `href="#"` with your CV PDF
4. GitHub button `href="#"` with your repository URL
5. Gallery placeholders with your achievement images

## Run
Double-click `index.html`, or open it with VS Code and use Live Server.

## Important
The assignment upload shown here selects a file in the browser. It does NOT permanently upload it to a server. For permanent uploads, you need a backend/storage service.
